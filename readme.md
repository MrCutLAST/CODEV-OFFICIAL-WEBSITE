# Codev — Your Ultimate AI Workspace 🚀

**Codev** is a powerful, browser-based AI Workspace designed for developers and creators. It brings together advanced AI models, context sharing, and custom plugins into a single, seamless environment.

🌐 **Live Demo:** [https://codev.bytecraft.workers.dev/](https://codev.bytecraft.workers.dev/)

---

## ✨ Key Features

- **Multi-AI & Think Mode:** Run parallel model reviews, synthesis, and deep reasoning to solve complex coding tasks.
- **Model Context Protocol (MCP) Support:** Seamlessly connect and load custom tool configurations securely within your browser.
- **Rich Plugin Ecosystem:** Connect directly with essential services like GitHub, Notion, Supabase, Vercel, Canva, and Netlify.
- **Privacy First:** Your API keys, tokens, and chat history are saved strictly in your browser's local storage.
- **Built-in Web Preview & Console:** Write HTML/CSS/JS and preview your static websites instantly inside the workspace, complete with real-time diagnostics.
- **Voice & Media Enabled:** Easily attach images, record video, or use voice commands for a multimodal workflow.

---

## 🛠️ Tech Stack & Powered By

- Built on top of **Cloudflare Workers** for lightning-fast edge deployment.
- Compatible with top AI providers (OpenAI, Anthropic Claude, Google Gemini, DeepSeek, OpenRouter, and more).
